# C01 Categories test plan

The C01 SQL smoke test covers category creation, renaming, one-level nesting, archive and restore
rules, active-product moves, tenant isolation, permissions, audit rows, and
`app.category_with_children` product filtering.

Run with:

```text
npm run db:smoke -- supabase/tests/c01_categories_test.sql
```

The contract tests cover strict request bodies, name trimming and limits, update validation, and
the archive conflict detail shape.
