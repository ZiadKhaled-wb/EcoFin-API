## Provisioned rows

One organization, org_settings, eta_settings (disabled), main branch MAIN, main safe, installment policy version 1 (12 months, zero markup), unlinked OWNER employee, open platform invite, and org.provisioned audit row. The seed adds no further mandatory per-shop rows. No demo products, warehouses, ledger movements, balances or document counters are inserted; existing triggers/functions initialize derived state when used. The safe starts at zero through v_cash_balances.

## Access exceptions

security_guards_test.sql explicitly allows the four platform admin functions: platform super admin; checks app.is_super_admin(). Invite lookup/accept are service-role-only pre-session functions. Platform endpoints ignore x-org-id and use the caller JWT.
