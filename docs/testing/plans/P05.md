## Access and implementation notes

Platform functions check app.is_super_admin(), set audit target, and use the caller JWT. get_subscription_status is a read-only session helper. app.require_module has no client grants; public.require_module is a minimal authenticated wrapper because the app schema is private and not exposed by PostgREST. It resolves the session employee and invokes the private helper. No existing feature is module-gated. Private subscription_snapshot avoids duplicating state/date computations.

P01/F04/F05 contained date-based login/session refusals; P05 removes those in a new migration and API login path so only require_permission enforces read-only writes, with export.data allowed. Old migrations stay unchanged. The dev seed needs no plan change.
